# Keypad UI screenshots

These 480×320 renders document the intended normal 3.5-inch landscape keypad
surface:

- `keypad-home-disarmed.png` — normal disarmed state
- `keypad-armed-countdown.png` — nonblocking exit countdown
- `keypad-triggered-alarm.png` — local alarm state with PIN prompt

The SVG files are retained as editable sources. These are UI design references,
not final LCD-driver output; the selected display controller, touch coordinates,
fonts, and colors still require bench verification.
