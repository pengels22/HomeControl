# HomeControl Tablet Android App

This directory is a standalone Android Studio project copied from the tablet app workspace.

## Open for development

In Android Studio, choose **Open** and select this folder:

`HomeControl/05_PNL/tablet`

Android Studio should import the Gradle project from `settings.gradle.kts` and open the `app` module. Use Android Studio's bundled JDK if Terminal Gradle commands report that Java is unavailable.

The original project-specific `local.properties`, IDE metadata, build outputs, and Gradle caches are intentionally not stored in Git. Android Studio will recreate its local configuration when the project is opened.

The application module is `app`, with application ID `com.example.sonicsatilite`.
